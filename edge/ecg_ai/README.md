# ECG Analysis (planned)

Status: **under implementation and testing** (see the Specathon deck, slide 8).

Goal: AI-assisted ECG analysis and decision support running offline on Raspberry Pi 4 / Jetson Nano.
Until a validated model exists, `sanjeevani.triage` (rule-based) is the baseline any model must be compared against.
Only validated, de-identified data may be used for training. See [SAFETY.md](../../SAFETY.md).
